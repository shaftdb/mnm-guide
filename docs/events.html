Keeping it updated

  1. Run python3 tools/events_fetch.py. It reads the official news feed (monstersandmemories.com/updates?format=rss) and the official patch notes pages, and stops after 8 missing numbers in a row.
  2. Run python3 build.py and commit data/events.json and docs/.
  3. Add a milestone only when an official post states the date, with that post's URL (the _MILESTONES list in modules/events.py).
