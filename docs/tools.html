Tools: timer, XP/hr, camp notes

Small helpers that run in your browser. Everything you enter is saved only in this browser (localStorage); nothing is sent anywhere. The tools use only the numbers you type in strategy. They hold no game data.

Spell timer

Add a timer for a buff, debuff or respawn. Type the duration as seconds or m:ss. Timers keep counting after a reload.

    XP per hour

    Read your XP bar percentage at the start and now. The calculator gives XP %/hr and time to level.

    Camp notepad

    Notes per camp (spawn times, pull spots, who's camping). Saves as you type.
