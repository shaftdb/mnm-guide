Example — Inlaid Jade Copper Ring (WIS): effectively 1× Copper Bar (wire) + 2× Enchanted Copper Bar (setting) + 1× Chipped Jade + Crude Ring Mold. Enchanted bars need an Enchanter (spell Enchant Copper at L1) or Enchanting skill — ask guild enchanter.

Example — Jade Copper Necklace: 1 Wire + 1 Mounting + 2 Chain Links (12 bars) + Chipped Jade + mold → 13× Copper Bar + 1× Enchanted Copper Bar + gem.

Wiki "5-piece set ≈ 11 bars + 6 enchanted + 5 gems" rule of thumb may be outdated (page banner). Prefer summing the component recipes above; treat any shortcut total as unverified.

Prioritize Jade (WIS), then Emerald (STA). Gem quality tiers (Chipped → Flawed → …) rise with metal tier on the wiki tables.

Quick hand-in checklist strategy

  1. Copper Bars (big stacks) + Rawhide Scraps/Straps → Chain set + mace + shield
  2. Wood + Resin + LQ pelts → tanners → canvas/straps
  3. Jade / Emerald gems + bars → JC for WIS/STA jewelry (plus enchanter for enchanted bars)
  4. Tin Bars when available → Bronze upgrade path
  5. Corroded bronze / tattered rawhide → smith & leatherworker scrap loops
  6. Fine Wood / Limestone → higher tanning tiers later
